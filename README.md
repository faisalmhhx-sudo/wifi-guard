# حارس الواي فاي (WiFi Guard) 🛡️

تطبيق جوال (أندرويد + آيفون) لاكتشاف ومراقبة الأجهزة المتصلة بشبكة الواي فاي،
والتنبيه فوراً عند دخول أي جهاز جديد — مستوحى من **Fing** و **Ekahau** و **WiFi Weave**
مع واجهة عربية كاملة (RTL).

---

## المزايا الرئيسية

| الميزة | الوصف | المصدر المُلهِم |
|--------|-------|-----------------|
| كشف الأجهزة | مسح الشبكة ومعرفة كل جهاز متصل وعددهم | Fing |
| نوع الجهاز | تخمين النوع (جوال، كاميرا، تلفزيون…) من MAC والمنافذ واسم المضيف | Fing Device Intelligence |
| الشركة المصنّعة | معرفة الشركة من بادئة MAC (OUI) — محلياً وعبر الإنترنت | Fing |
| تفاصيل الجهاز | IP، MAC، اسم المضيف، المنافذ المفتوحة، أول/آخر ظهور | Fing |
| تنبيه الدخول الجديد | مراقبة دورية في الخلفية + إشعار فوري عند دخول جهاز غير معروف | Fing Alerts |
| تحليل الواي فاي | الشبكات المجاورة، قوة الإشارة، القنوات، نوع التشفير | Ekahau / WiFi Weave |
| توثيق/تسمية الأجهزة | تسمية الأجهزة وتحديد الموثوق منها لتقليل التنبيهات | Fing |
| التحكم بالراوتر | فتح صفحة الراوتر أو حظر تلقائي (للراوترات المدعومة) | Fing / Fingbox |

## كيف يعمل الاكتشاف؟ (الأساس التقني)

1. **تحديد الشبكة**: نقرأ IP الجهاز والبوابة (`network_info_plus`) ونستخرج الشبكة الفرعية.
2. **مسح متزامن**: نرسل `ping` لكل عنوان من `.1` إلى `.254` بتزامن محدود (سريع).
3. **جدول ARP**: على أندرويد نقرأ `/proc/net/arp` لربط كل IP بعنوان MAC.
4. **OUI**: نستخرج الشركة المصنّعة من أول 6 خانات من MAC.
5. **عكس DNS + منافذ**: نجيب اسم المضيف ونفحص أشهر المنافذ لتحسين التصنيف.
6. **التصنيف**: نخمّن نوع الجهاز من مجموع الإشارات (مثل فكرة Device Intelligence في Fing).

المراقبة الخلفية تعيد هذه العملية دورياً (`Workmanager`)، وتقارن بالأجهزة المحفوظة،
وترسل إشعاراً عند أي جهاز جديد.

## ⚠️ حدود تقنية مهمة (اقرأها)

- **الطرد/الحظر يتم عبر الراوتر فقط.** لا يوجد تطبيق جوال (حتى Fing) يقدر يقطع
  النت عن جهاز بدون وصول للراوتر — بسبب قيود أمان أندرويد و iOS. البديل الوحيد
  بدون راوتر هو *ARP Spoofing* (زي جهاز Fingbox العتادي) وهو غير موثوق وممنوع في
  App Store. لذلك التطبيق يوفّر: (١) فتح صفحة الراوتر، و(٢) حظر تلقائي للراوترات
  التي تدعم واجهة برمجية (MikroTik/OpenWrt).
- **iOS محدود**: قراءة عناوين MAC للأجهزة الأخرى ومسح الشبكات المجاورة مقيّدة
  على آيفون. الاكتشاف على iOS يعتمد أكثر على mDNS/Bonjour وعكس DNS.
- **أندرويد**: مسح الواي فاي يتطلّب صلاحية الموقع، والحد الأدنى لتكرار المهام
  الخلفية 15 دقيقة (قيد نظام أندرويد).

## طريقة التشغيل

المتطلبات: [Flutter SDK](https://docs.flutter.dev/get-started/install) 3.19 أو أحدث.

```bash
# 1) داخل مجلد المشروع
flutter pub get

# 2) إنشاء ملفات المنصّات (إن لم تكن موجودة)
flutter create . --platforms=android,ios

# 3) التشغيل على جهاز/محاكي
flutter run

# لبناء نسخة أندرويد للتوزيع:
flutter build apk --release
```

> ملاحظة: مجلدا `android/` و `ios/` هنا يحتويان ملفات الإعداد الأساسية
> (الصلاحيات). أمر `flutter create .` يكمل باقي ملفات المنصّة تلقائياً.

## خارطة طريق مقترحة (تطوير مستقبلي)

- اختبار سرعة الإنترنت + رسوم بيانية (مثل Fing).
- خريطة حرارية لتغطية الواي فاي (مثل Ekahau) عبر تحرك المستخدم.
- قاعدة OUI كاملة من IEEE بدل القائمة المختصرة.
- fingerprinting أدق عبر mDNS/UPnP/DHCP لتحسين تصنيف الأجهزة.
- تكامل أعمق مع طرازات راوترات إضافية للحظر التلقائي.
- سحابة اختيارية لمزامنة الأجهزة والتنبيهات بين أجهزة المستخدم.
